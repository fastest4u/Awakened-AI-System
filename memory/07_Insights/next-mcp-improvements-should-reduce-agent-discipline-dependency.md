For the project-memory MCP, the highest-value next improvements are guardrails and automation that make correct memory behavior harder to skip: automatic lifecycle enforcement, task-aware retrieval presets, end-of-task health gates, stale/follow-up surfacing, and clearer client integration diagnostics. Existing notes show the system already has bootstrap, context packs, usage scoring, compaction, slash commands, and session-end vault health summaries, so the next roadmap should prioritize reliability and observability over adding more note types.
