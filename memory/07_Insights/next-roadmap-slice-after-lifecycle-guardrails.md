After lifecycle guardrails and qualityGate, the best next project-memory MCP improvement is task-aware retrieval presets for memory_contextPack. This should add modes such as coding, debugging, review, deploy, planning, and docs, each with different default include flags, type weights, recommended reads, and checklist hints. This is higher leverage than client diagnostics because it improves every task's context quality and makes later follow-up radar and diagnostics easier to route by task type.
