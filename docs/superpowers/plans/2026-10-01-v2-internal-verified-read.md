## Global Constraints

- Initial operation is only `verify-published-view`, returning metadata, not memory content; no arbitrary callback, SQL, evaluator facade, model-selected binding, public registration or provider.
- Preserve `memory_v2Status`-only registration, content/promotion denial, `productionReady:false`, `requireFullEvidence=true`, current Codex desktop and empty V2 with no V1 import/retrieval/fallback.
- Response budget: 2000 ms session-strong; 5000 ms project-strong; trusted override integer 0..30000 ms. Supervisor request arrival before queue/startup/ownership I/O; one monotonic clock, no resets.
- One adapter/binding per server composition; 8 unsettled requests including the active request; one read or cleanup child at a time. Publication waits: 50 ms, at most 600 attempts, within original remaining budget.
- Manifest maximum 64 KiB; new read image maximum 64 MiB, legacy 512 MiB helper limit unchanged. Request/bootstrap 8 KiB; receipt/envelope 16 KiB; at most 8 bounded stage/terminal messages; each child output stream over 4 KiB fails.
- Ownership record maximum 8 KiB. Separate fixed 2000 ms cleanup observation includes at most 100 ms grace, termination, exit, owned-lock cleanup and record closure; never restart that window per stage.
- Known closed-lane/old-epoch messages cannot succeed or poison a later request. Current-lane unknown identity/invalid IPC fails. No success before image/reader/lock/child/record closure and final authoritative observation.
- Prepared/disabled deny. Read-only recovery remains `FRESH_START_CONTENT_UNVERIFIED`; byte SHA and committed anchors are not authenticated replay/privacy/recovery proof.
- No live transcripts, secrets, host setup/config/trust, existing store initialization/reset, external writes, push/merge/hosted CI/deploy/activation. Tests use owned synthetic stores only.
- Reuse unchanged accepted F1/host-preparation evidence. Run task-focused TDD, invalidated regressions and one increment gate, not another broad F1/full-suite assurance loop. Applicable final release checks are not waived.

## Review Focus

- A path replaced after native open must not retain admission just because earlier identity matched; test authoritative-file provenance before/after both snapshots (Task 3).
- Valid UTF-8 branch refs near 1024 bytes and descriptor/accessor-bearing objects must retain exact bounds without evaluating getters or allocating an oversized wire first (Task 1).
- A matching image SHA with forged singleton metadata must still refuse; shared validation must preserve V1 error behavior (Task 2).
- A response timer delayed beyond expiry must never admit a late valid receipt; epoch/cancel/exit races settle once (Task 5).
- Crash between durable launch intent and PID observation, or late successful ownership I/O after expiry, must not launch/reuse a lane on restart (Task 5).
